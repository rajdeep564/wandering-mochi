    Adopt Mochi

    1. Install her: 
      npm install wandering-mochi
    2. Add her to your app: 
      import { adoptMochi } from "wandering-mochi";

adoptMochi();
      In React, call it inside useEffect and return the result. That's all she needs to live on your site.
    3. Want her to visit and review you? Run this, then follow the link it prints: 
      npx wandering-mochi invite

    You can personalise her with adoptMochi({ name, owner, photo }), where photo is a CSS selector for a picture she will nap under.
